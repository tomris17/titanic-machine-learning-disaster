This repository contains an end-to-end machine learning solution for the famous **Kaggle Titanic** competition. The goal is to build a predictive model that answers the question: *"what sorts of people were more likely to survive?"* using passenger data (such as age, sex, ticket class, and fare).

---

## 📊 Project Overview
* **Objective:** Build a robust binary classification model to predict passenger survival outcomes (evaluated using prediction accuracy).
* **Key Steps:**
  * Exploratory Data Analysis (EDA) investigating survival rates across gender, passenger class, age groups, and family sizes.
  * Data preprocessing and feature engineering (handling missing values, extracting titles from names, and creating family size features).
  * Model Training using classification algorithms (e.g., Logistic Regression, Random Forest, or Decision Trees).
  * Interactive web dashboard deployment via **Streamlit** for real-time survival prediction.

---

## 🛠️ Tech Stack & Libraries
* **Python**
* **Pandas & NumPy** (Data Cleaning & Manipulation)
* **Scikit-Learn** (Classification Models & Evaluation Metrics)
* **Matplotlib & Seaborn** (Data & Feature Visualization)
* **Streamlit** (Interactive Dashboard)
